# Security Policy

## Reporting a vulnerability

**Please do not open a public issue for security reports.**

Use GitHub's private vulnerability reporting — the **"Report a vulnerability"**
button on this repository's [Security tab](../../security/advisories/new). We aim
to acknowledge within 3 working days and keep you updated through the advisory.

Findings are triaged against the SLAs tracked in
[`smart-pet-docs/security/`](https://github.com/jubasjl76-eng/smart-pet-docs/tree/main/security):
Critical fixed within 7 days, High within 30. Accepted risks are recorded in
[`exceptions.md`](https://github.com/jubasjl76-eng/smart-pet-docs/blob/main/security/exceptions.md).

## Supported versions

Smart Pet is pre-1.0 and under an active hardening track. Only the current tip
of the integration branch (`development`, or `main` for libraries and firmware)
receives security fixes; older tags do not.
